# Identity & Access Management (IAM) Framework

## Overview
Designed and implemented a comprehensive role-based access control (RBAC) model applying least-privilege principles for a user management system, developed as a graduation project at King Saud University.

## Key Implementation Steps
* **Role-Based Access Control (RBAC):** Configured and structured 3 distinct user roles within the test environment, strictly implementing least-privilege access principles.
* **Security Controls & Policies:** Successfully implemented Multi-Factor Authentication (MFA) and enforced strict Group Policies to elevate overall security posture.
* **Privileged Account Optimization:** Audited and reduced the number of accounts with administrative rights from 8 down to 2 in the test environment.
* **Governance & Documentation:** Documented the complete access policy along with the Joiner/Mover/Leaver (JML) lifecycle process, and successfully presented the framework to the academic project panel (Grade: A+).

## Technologies & Frameworks
* **Domain & Directory Services:** Active Directory, Group Policies
* **Security Protocols:** MFA (Multi-Factor Authentication), RBAC
* **Framework Principles:** Least-Privilege Access, JML Lifecycle Management
